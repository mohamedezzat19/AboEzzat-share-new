# AboEzzat Share

تطبيق أندرويد لتصفح المواقع واكتشاف روابط الوسائط وإرسالها إلى تطبيق **AboEzzat Receiver** على الشبكة المحلية.

## الوظائف الحالية
- فتح الروابط والتنقل داخل المتصفح.
- اكتشاف روابط الفيديو والصوت المتاحة في الصفحات ومحاولة إرسال الرابط المحدد إلى جهاز الاستقبال.
- إرسال روابط IPTV المتوافقة.
- اختيار صور وملفات صوت/فيديو محلية وإتاحتها مؤقتًا عبر خادم محلي على المنفذ **8082**، مع دعم طلبات نطاق البايت لتسهيل التشغيل والبحث داخل الفيديو.
- إرسال عدة صور وعرض الشرائح، وإدارة الروابط المحفوظة والمفضلة والسجل.
- تنزيل الوسائط والنسخ الاحتياطي/استعادة بيانات التطبيق بصيغة JSON.
- اكتشاف جهاز الاستقبال تلقائيًا، مع إمكانية ضبط عنوان IP يدويًا.

## إعداد الاتصال
1. ثبّت وافتح **AboEzzat Receiver** على جهاز Android TV أو الجهاز الذي سيشغّل الوسائط.
2. وصّل الهاتف وجهاز الاستقبال بالشبكة المحلية نفسها.
3. من تطبيق Share، استخدم اكتشاف جهاز الاستقبال أو أدخل عنوان IP الظاهر في تطبيق Receiver.
4. عند إرسال ملفات محلية، اترك تطبيق Share يعمل على الهاتف طوال التشغيل لأن جهاز الاستقبال يقرأ الملف من خادم محلي مؤقت.

يستخدم بروتوكول الاستقبال TCP على المنفذ **8081**، ويستخدم Share المنفذ **8082** لتقديم الملفات المحلية. يجب أن تسمح الشبكة المحلية بالاتصال بين الجهازين. بعض المواقع تستخدم DRM أو روابط مؤقتة/محمية لا يمكن إرسالها مباشرة.

## البناء
يتطلب Java 17 وAndroid SDK (API 34). من جذر المستودع:

```bash
gradle assembleDebug
```

ملف APK الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

يمكن أيضًا تشغيل سير عمل **Build AboEzzat Share APK** من تبويب Actions أو تنزيل artifact الناتج عن آخر تشغيل ناجح.
