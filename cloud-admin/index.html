تنبيه إعداد مهم

هذه لوحة حقيقية تعتمد على Firebase بعد إعداد مشروعك. لن تظهر الأجهزة ولن تُرسل أوامر قبل وضع إعدادات Firebase الصحيحة وتفعيل Authentication وRealtime Database ونشر القواعد. لا تفتح المنفذ المحلي 8081 على الإنترنت.

1. إعداد الاتصال

أنشئ Firebase Web App، ثم ضع إعدادات التطبيق العامة أدناه. لا تضع service-account key أو أي سر إداري في هذه الصفحة.

الإعداد محفوظ في ذاكرة الصفحة فقط لهذه الجلسة، ولا يُرسل إلى أي جهة غير Firebase.

التشخيص (Diagnostics)
